# tree-sitter-java

[![CI][ci]](https://github.com/wotjr1649/tree-sitter-java/actions/workflows/ci.yml)

Java grammar for [tree-sitter](https://github.com/tree-sitter/tree-sitter).

This repository continues [tree-sitter/tree-sitter-java](https://github.com/tree-sitter/tree-sitter-java) from
v0.23.5 with its history ([NOTICE](NOTICE),
[ADR-0001](docs/decisions/ADR-0001-continue-from-upstream.md)). It is not published to package registries; the
`tree-sitter-java` packages on crates.io, npm and PyPI are upstream's.
