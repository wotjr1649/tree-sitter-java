# Java 25 structural oracle mapping

Grammar base `b28fed5` with tree-sitter CLI `0.27.2` and Temurin `25.0.5+8` in parse-only mode (`--release 25`, preview disabled).
The comparison uses the original UTF-8 bytes and half-open `[start, end)` intervals. Convert `SourcePositions` UTF-16 indices before comparing.
A tree-sitter CLI point uses a byte column. The Node binding reports UTF-16 code-unit indices and needs the same conversion as javac.
Keep original line endings and Unicode spelling. Reject an offset in the middle of a surrogate pair. A javac `NOPOS`, reversed interval or known zero-width synthetic range has no standalone check.

`compare` checks the selected interval, kind and namedness, plus the documented syntax roles and attributes. `compare-range-only` checks the projected interval in its role.
`skip` leaves child checks enabled. Select context before looking up a range. Ignore comment extras when finding children, while preserving the original coordinates.
For same-range wrappers, select by parent and child role. Use the javac child’s own row for nested checks, including ordered operand intervals for precedence and associativity.
A **field** means a tree-sitter field name. Other labels in the Parts column refer to javac getters or ordered CST children. An anonymous token is explicitly labeled.

## Comparator input

`mapping.json` is indexed directly by javac kind. Each entry contains a `variants` array.
`variants` lists context-specific rows before the `default` row, when one exists.
`ts` holds `{kind, named}` candidates. `range` names a projection described by `rangeDescription` and the table below. An empty `ts` with a projection selects the child in the documented role.
`when` contains javac attributes already available in the prototype for the relevant variants. Other context keys require information from the javac parent/getters or the corresponding source role.
Resolve the expected branch from javac or source context before searching for a CST match. Count unavailable contexts separately until the comparator can dispatch them.
A node whose kind has only `when` rows and whose attributes select none is a tool fault (exit 2). The loader also exits 2 on a malformed or duplicate (kind, context) row and on a context the runner never emits; the context of a `when` row is only a label.
`operatorField` locates a token, `operatorPosition` is relative to the operand, `fields` maps CST fields to javac getter roles, and `qualifierFinalToken` describes the required token at the end of a qualified-super reference.
A full `compare` result requires the documented part checks in addition to the node kind and interval.
The follow-up context rules cover annotated varargs elements, annotated catch qualifications, implicit classes, synthetic enum type names, and parse-only mixed switch labels. They preserve the ordinary rows and the tree-error verdict for the whole input.
The [comparator](../../scripts/structural-compare.mjs) implements case, constructor-call, binding-tail and
wildcard projections plus several attributes. It also checks the `provider` field ranges of `PROVIDES` directives.
The remaining part checks in this table require richer role and child data.

| Range rule | Interval |
|---|---|
| `same` | Compare the whole half-open UTF-8 interval of the javac tree and the selected CST node or token. |
| `none` | The row is outside standalone range comparison. Preserve its comparable descendants. |
| `constructor-call` | Project from the start of explicit_constructor_invocation to the end of its arguments field, excluding the statement semicolon. |
| `constructor-selector` | For an unqualified selector with explicit type arguments, use type_arguments.start through constructor.end. |
| `colon-case` | Use a single-label group directly. For a group with multiple labels, use label.start through colon.end for nonfinal labels and label.start through group.end for the last label. |
| `constant-case-expression` | Use the same-ordinal non-extra expression child of switch_label, without case keyword, comma, guard or delimiter. |
| `instanceof-binding-tail` | Use the first non-extra token after the instanceof token through name.end. The parent INSTANCE_OF row verifies RHS shape. |
| `wildcard-core` | Use the whole wildcard interval if no leading annotation is wrapped separately by javac. Otherwise use the start of the anonymous ? through wildcard.end. |

## CST wrappers, hidden rules and aliases

| CST kind or grammar rule | Comparator treatment |
|---|---|
| `guard` | CaseTree.getGuard() ranges over the expression after when. Compare its child and whether a when clause is present. |
| `switch_label` | Contains case/default, label elements and optional guard. Compare individual labels and guard, then the enclosing CASE. |
| `switch_block` | Container for ordered CASE entries. Compare through SWITCH/SWITCH_EXPRESSION. |
| `record_pattern_body` | Groups nestedPatterns with parentheses; compare through DECONSTRUCTION_PATTERN. |
| `formal_parameters`, `inferred_parameters` | CST parameter-list wrappers, with no corresponding list tree. A bare lambda parameter is unwrapped. |
| `argument_list`, `type_arguments`, `annotation_argument_list` | CST list wrappers include delimiters. Match each AST list element to its child in order. |
| `element_value_pair` | The explicit name=value form is a javac ASSIGNMENT. Use the annotation-element variant. |
| `dimensions_expr`, `dimensions` | Sized dimensions wrap an expression and annotations. Empty dimensions flatten one or more bracket pairs. Compare through NEW_ARRAY/ARRAY_TYPE. |
| `resource_specification`, `resource` | TryTree exposes resources directly. A resource can wrap a variable declaration, identifier or field access. |
| `finally_clause` | TryTree exposes its block. Compare that child independently. |
| `type_bound` | TypeParameterTree exposes bound trees directly. Bounds separated by & are ordered children. |
| `switch-rule expression_statement` | When the enclosing switch is an expression, the CST wrapper includes the semicolon while javac exposes the value directly. |
| `string_fragment`, `multiline_string_fragment`, `escape_sequence`, `string_interpolation`, `template_expression` | JDK 25 matches whole STRING_LITERAL tokens. Template syntax has no Java 25 preview-off counterpart. |
| `expression`, `primary_expression`, `statement`, `declaration`, `_literal`, `_type`, `_simple_type`, `_unannotated_type`, `module_directive` | Grammar alternatives or supertypes, with top-level node-types subtype lists rather than emitted node instances. |
| `_reserved_identifier`, `_annotation`, `_pattern_modifiers`, `_additional_case_*` | Hidden rules and public aliases. Use the emitted kinds, including additional pattern/type/record/component aliases and typed _ as identifier. |

## Observed boundary cases

- `(a) - b` and `(a) + b` are binary trees with parenthesized left operands. `(int) -b` is a cast with a unary value. `(a) -> b` has an inferred parameter list.
- `a < b > c` is a parse-only control. The pinned JDK accepts its syntax and rejects full compilation. The comparison seed uses `a < b == c > d`, which fully compiles.
- The qualified-super control compiles and parses without errors. javac produces a qualifier `MEMBER_SELECT` ending in member name `super`. The grammar produces `scoped_type_identifier` containing `type_identifier` for the keyword. The method-reference root ranges coincide, so the qualifier check is essential.
- A bare record-component `_` produced javac intervals `[103,103)` and `[107,107)` in the nested-record seed. With trivia after the token the control reports `[662,654)`. Its CST has an ordinary underscore token.
- The UTF-8 seed gives javac `PLUS` offsets `[70,77)` in UTF-16 and `[76,83)` in UTF-8, the same byte interval as `binary_expression`. The test preserves the supplementary character and the source's final CRLF.
